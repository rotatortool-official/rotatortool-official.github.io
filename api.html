The same data Rotator's own site and Telegram bot read: about 290 crypto assets and tokenized stocks, rescored every 15 minutes, with the numbers behind every score. This page exists so developers and AI agents can query it directly instead of scraping the UI.

All endpoints are standard PostgREST: plain HTTPS GET requests, JSON responses, filterable and sortable with query parameters. Agents: the machine-readable contract is openapi.json.

Start here: the scored universe
Every 15 minutes the scoring engine runs once over the whole universe and writes one run (a header row) and one item per asset. This is the core dataset; everything else on this page is derived from it or recorded alongside it.
Read the newest run that has items, not simply the newest run. The run header is written a moment before its items. A request that lands in that gap gets a run with zero items. Ask for the newest two runs and use the first one that returns items, or use the embedded form below and check that the item list is not empty.
GET /signal_runs
One row per scoring run. The newest is the current state of the market as the engine sees it.
curl "https://wyvwycatgexpbugzkdfw.supabase.co/rest/v1/signal_runs?select=id,as_of,engine_version,cycle_label,universe_size,eligible_count&order=as_of.desc&limit=2" \ -H "apikey: <anon key>" -H "Authorization: Bearer <anon key>"

GET /signal_run_items
One row per asset per run: its score, its label, and the components behind them. About 290 rows per run. The jsonb columns are large, so select only the columns you need.

The daily "rotate out of A, into B" pairs, written once a day at 19:07 UTC from the latest run: the five highest scores paired with the five lowest eligible ones. Always filter on source. The table also holds experiments that are recorded for grading and never published (see below); an unfiltered query mixes them in. What the evidence says
Measured on 771 days of history (2024-06 to 2026-08, about 115 assets a day), not on live results:
· The score ranks in the right direction. A higher score preceded better 30-day relative performance: rank correlation +0.053. The share of each score decile that beat the market median rose from 45.1% (lowest) to 51.8% (highest). It is a small edge, and it was measured on the history the engine was tuned on.
· So the 'buy' zone is not a prediction of outperformance. It marks the low end of the score, the assets that have lagged. The published rotation pairs (sell the five highest scores, buy the five lowest) had a positive 30-day spread on 46.8% of 3,855 pairs, below the ~50% of two assets picked at random. The pairs are published and graded as a test.
· No live accuracy claim yet. Live calls are graded at 30 days on the track record. It will take months of live data before it can confirm or contradict the figures above.
Rate limits & fair use
No key tiers and no published hard limit yet. This runs on the same infrastructure as the live site, so be reasonable: runs change every 15 minutes, so polling faster buys nothing; cache what you read; select only the columns you need; and do not bulk-scrape in parallel. If you need higher volume or an SLA, get in touch through the CONTACT link on the main site before building against this at scale.
Scope, stated plainly: nothing here is a security audit, a long-term valuation, a usage or TVL metric, or sentiment analysis. The scores measure 7–30 day price momentum, macro-relative strength and, for crypto, supply and unlock mechanics. Nothing else. This is not financial advice; nothing here, machine-readable or not, should be the sole basis for deploying capital.
